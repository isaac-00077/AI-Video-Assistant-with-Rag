What's inside

Built different. Built in one file.

Every feature below runs from a single HTML document — no build step, no frameworks, no CDN.

🧊

Live WebGL Shader

A hand-written fragment shader renders flowing aurora-like waves in real time, reacting to your mouse position with a soft glow.

✨

Glassmorphism UI

Frosted-glass panels, pill navigation, and layered borders create depth while the shader animates underneath.

🎬

Scroll Animations

IntersectionObserver reveals sections with staggered fade-up transitions as you move down the page.

🖱️

Interactive Cards

Cards light up with a radial gradient that follows your cursor, plus lift-on-hover physics.

📊

Animated Counters

Stats count up from zero the moment they scroll into view, with easing that feels satisfying.

📱

Fully Responsive

Fluid typography, adaptive grids, and a mobile menu keep it sharp from phones to ultrawide monitors.
